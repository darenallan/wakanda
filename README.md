# Luxury Lounge — page d'accueil

Page d'accueil d'un **lounge de luxe** aux inspirations africaines (icônes adinkra) : hero, présentation de l'ambiance, carrousel du menu, plan de salle interactif et pied de page.

Projet généré avec **Figma Make** depuis la maquette [Figma](https://www.figma.com/design/zj54N5IGgMvSaYOTmhVbvN/Luxury-Lounge-Landing-Page), puis adapté.

## Stack

React, TypeScript, Vite, Tailwind CSS, composants shadcn/ui (Radix) et MUI. Les photos viennent d'Unsplash (voir [`ATTRIBUTIONS.md`](ATTRIBUTIONS.md)).

## Lancer

```bash
npm install
npm run dev      # serveur de développement
npm run build    # build de production
```

La structure se trouve dans `src/app/` (`App.tsx`, `components/`, pages et contextes). Les consignes de conception sont dans [`guidelines/Guidelines.md`](guidelines/Guidelines.md).
